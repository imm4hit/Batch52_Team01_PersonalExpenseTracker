 SPENDEMIC 

 || Smart Personal Expense Tracker using C ||
  An epidemic of spending. A cure for budgeting.

< SPENDEMIC is a simple C program designed to help keep track of where that money actually goes.
Users can record their expenses, set a monthly budget, check how much they've spent, and see which categories are taking up most of their money.>

Features

- Set monthly budget
- Add and manage expenses
- View transaction history
- Categorize expenses
- Calculate total expenditure
- Monitor remaining budget
- Identify highest-spending category
- Budget alerts and spending insights

Concepts Used

- Structures
- Arrays
- Functions
- Loops
- Conditional statements
- Input validation

 Built With

- C Programming Language
